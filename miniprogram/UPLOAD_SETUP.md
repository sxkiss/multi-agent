# 上传密钥配置说明（miniprogram-ci 免扫码上传）

## 为什么需要这个

微信公众平台网页登录**强制管理员微信扫码**，账号密码无法绕过。
因此改用官方命令行工具 `miniprogram-ci`：只需在后台下载一次密钥，
之后上传即可全自动化，无需扫码、无需开发者工具。

## 你需要做的（约 2 分钟，只需做一次）

### 1. 下载上传密钥

1. 打开 https://mp.weixin.qq.com 并扫码登录
2. 左侧菜单：**开发** → **开发管理** → **开发设置**
3. 找到「**小程序代码上传**」区块 → 点击「**生成**」上传密钥
4. 下载得到 `private.<appid>.key` 文件
5. **同时**开启「IP 白名单」，填入：

```
175.153.160.165
```

### 2. 把密钥放到这里

把下载的 key 文件放到：

```
/home/sxkiss/bt/miniprogram/private.key
```

（文件名固定为 `private.key`，已加入 .gitignore，不会入库）

### 3. 告诉我"可以了"

之后上传、预览、生成二维码都由我执行，你不用再操作。

## 安全性说明

- 密钥**只能上传代码**，不能登录后台、不能改配置、不能提审发布
- 配合 IP 白名单，即使密钥泄露，攻击者从其他 IP 也用不了
- 密钥已加入 .gitignore，不会被 git 提交

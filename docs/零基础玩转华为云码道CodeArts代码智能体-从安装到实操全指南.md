## 一、实验概述

### 1.1 实验背景

随着大模型技术在软件工程领域的落地，AI 编程助手已成为开发者提升效率的重要工具。华为云码道（CodeArts）代码智能体是华为云 CodeArts 软件开发生产线中的智能开发能力，它能够理解工程上下文、生成与补全代码、解释逻辑、生成单元测试、辅助定位并修复缺陷，甚至以 Agent 模式自动完成多步骤开发任务。

本实验面向**零基础**读者，从"如何拥有一个可用账号"讲到"如何用智能体完成一次真实开发任务"，帮助你在最短时间内跑通完整流程。

### 1.2 实验目标

完成本实验后，你将能够：

1. 说清 CodeArts 代码智能体的定位与核心能力；

4. 熟练使用代码补全、代码生成、代码解释、单元测试生成等基础功能；
5. 使用智能体模式（Agent）完成一次端到端的开发任务；
6. 掌握常见问题的排查方法。

### 1.3 适用人群

- 从未使用过 AI 编程工具的初学者
- 想快速评估 CodeArts 代码智能体能力的开发者
- 需要为团队引入 AI 编码能力的技术负责人

## 二、认识华为云码道（CodeArts）

### 2.1 什么是 CodeArts

华为云 CodeArts 是华为云一站式、全流程、安全可信的软件开发生产线，覆盖需求、开发、测试、部署等环节。**码道（CodeArts）代码智能体**则是其中面向"编码环节"的智能能力，以 AI 为核心，嵌入到 IDE 与研发流程中，为开发者提供实时的智能辅助。

可以把它理解为一个"懂你工程上下文"的编程搭档：它不仅知道你当前打开的文件，还能检索整个代码仓库，从而给出更贴合项目风格的答案。

### 2.2 代码智能体能做什么

- **代码补全**：根据上下文预测并补全整行或整段代码；
- **代码生成**：用自然语言描述需求，直接生成可运行代码；
- **代码解释**：为看不懂的代码生成逐行中文解释与注释；
- **单元测试生成**：为已有函数自动生成测试用例；
- **缺陷定位与修复**：结合报错信息与代码上下文，定位根因并给出补丁；
- **代码审查**：发现潜在风险、风格问题与可优化点；
- **Agent 模式**：理解一个较复杂的目标，自主拆解为多步并逐步执行。

### 2.3 核心能力一览

| 能力 | 典型使用场景 | 输入方式 |
| --- | --- | --- |
| 代码补全 | 写业务逻辑时减少重复敲键 | 直接编码触发 |
| 代码生成 | 从 0 写一个工具函数/脚本 | 自然语言指令 |
| 代码解释 | 接手他人代码、学习新技术 | 选中代码 + 指令 |
| 测试生成 | 补齐单元测试覆盖率 | 选中函数 + 指令 |
| 缺陷修复 | 线上报错排查 | 报错信息 + 代码 |
| 代码审查 | 提交前自检 | 选中变更 + 指令 |
| Agent 模式 | 多文件改造、脚手架搭建 | 一句目标描述 |

2. 点击右上角「注册」，按提示使用手机号或邮箱完成注册；

> 提示：建议绑定手机号并开启登录保护，后续实名认证与多端登录都更顺畅。

### 3.3 完成实名认证

根据国内云服务合规要求，使用 CodeArts 相关服务前通常需要完成实名认证：

1. 登录华为云控制台，进入「账号中心」；
2. 选择「实名认证」，按引导填写个人或企业信息；

1. 在华为云控制台搜索框输入「CodeArts」；
2. 进入 **CodeArts** 产品页，选择所需服务（如代码托管、CodeArts IDE 等）；

> 注意：不同能力（代码托管、流水线、IDE、智能体）的计费与开通方式不同，请按需选择，避免误购。

## 四、安装与配置

### 4.1 获取客户端

CodeArts 代码智能体通常有两种使用形态，任选其一即可：

- **形态 A：IDE 插件**——在你已有的 IDE（如 VS Code 系 IDE）中安装 CodeArts 智能体插件；
- **形态 B：独立 IDE**——直接下载安装 CodeArts IDE（内置智能体能力）。

获取方式：

1. 登录华为云 CodeArts 产品页；
2. 找到「下载」或「客户端」入口；
3. 根据你的操作系统下载对应安装包，并核对官方提供的校验信息。

> 安全提醒：请务必从华为云官方渠道下载，不要使用第三方来源的安装包。

### 4.2 安装 IDE

- **Windows**：双击安装包，按向导完成安装（建议不要装在含中文或空格的路径下）；
- **macOS**：打开 `.dmg`，将应用拖入「应用程序」；
- **Linux**：解压压缩包到目标目录，执行其中的启动脚本。

### 4.3 启用代码智能体

**若使用插件形态：**

1. 打开 IDE，进入扩展/插件市场；
2. 搜索「CodeArts」或「码道」；
3. 点击「安装」，安装完成后按提示**重新加载窗口**。

**若使用独立 IDE 形态：**

首次启动时，按引导登录华为云账号并同意相关服务条款，智能体能力即被激活。

### 4.4 登录与授权

1. 在 IDE 中找到智能体面板，点击「登录」；
2. 选择「华为云账号登录」，浏览器会打开授权页；
3. 在浏览器完成登录并点击「授权」，IDE 侧即自动完成登录；
4. 返回 IDE，确认左下角/状态栏显示已登录、服务可用。

### 4.5 界面初识

登录成功后，重点关注以下几个区域：

- **对话面板**：与智能体交互的主入口，输入自然语言指令；
- **编辑区**：智能体生成/修改代码的展示与接受区域；
- **上下文指示器**：显示当前引用了哪些文件、是否检索了整个工程；
- **模式切换**：在「问答模式」与「Agent 模式」之间切换。

## 五、实操一：代码补全与生成

### 5.1 代码补全

1. 新建一个文件，例如 `demo.py`；
2. 输入函数签名与注释，如：

```python
# 计算斐波那契数列的第 n 项
def fib(n):
```

3. 稍作停顿，智能体会给出补全建议；
4. 按 `Tab` 接受建议，按 `Esc` 拒绝。

### 5.2 代码生成

在对话面板输入自然语言需求，例如：

```
请用 Python 写一个函数，读取 CSV 文件并按某一列去重，返回去重后的 DataFrame。
```

智能体会生成代码并展示在编辑区，你可以：

- **接受**：插入到当前文件；
- **拒绝**：重新描述需求；
- **追问**：例如"把结果保存到新的 CSV 文件"。

### 5.3 实验结果验证

运行生成的代码，确认功能符合预期。若结果不正确，可直接在对话中描述现象，让智能体修正。

---

## 六、实操二：代码解释与注释

1. 打开一段你不太熟悉的代码；
2. **选中**这段代码；
3. 在对话面板输入：

```
解释选中的代码，说明它的输入、输出和执行流程，并补充中文注释。
```

4. 智能体会给出结构化解释与注释版本；
5. 对照原代码理解其逻辑，必要时可继续追问细节。

> 技巧：选中的代码范围越聚焦，解释越精准。

---

## 七、实操三：单元测试生成

1. 选中一个待测函数；
2. 输入：

```
为选中的函数生成单元测试，覆盖正常输入、边界输入和异常输入。
```

3. 智能体生成测试代码，注意检查：
   - 使用的测试框架是否与项目一致；
   - 断言是否合理；
   - 是否需要补充夹具（fixture）或 mock。
4. 将测试文件放入项目测试目录并运行，确认通过。

---

## 八、实操四：缺陷定位与修复

1. 复现缺陷，拿到完整报错信息（含堆栈）；
2. 在对话面板粘贴报错并附上相关文件；
3. 输入：

```
结合报错信息和当前工程，定位问题根因，并给出最小改动的修复方案。
```

4. 智能体会给出：
   - 可能的根因分析；
   - 需要修改的具体文件与位置；
   - 建议补丁；
5. 应用补丁后**重新运行**验证，确认缺陷消失且未引入新问题。

> 重要：AI 给出的结论必须经过你本人验证后再合入代码。

## 九、实操五：Agent 模式完成多步任务

Agent 模式适合"一句话描述一个较复杂目标"的场景。示例：

```
请在我的 Python 项目中新增一个健康检查接口：
1. 在 routes 目录新增接口文件；
2. 注册到主应用；
3. 补充对应的单元测试；
4. 最后运行测试确认通过。
```

智能体会：

1. **规划**：拆解为若干步骤并列出计划；
2. **执行**：逐步创建/修改文件；
3. **自检**：运行测试或检查语法；
4. **汇报**：输出改动清单与结果。

请务必在关键步骤后人工复核，尤其是涉及删除、覆盖与依赖变更的操作。

## 十、实操六：代码审查

1. 选中你本次的改动（或让智能体对比分支差异）；
2. 输入：

```
审查这段代码，指出潜在缺陷、安全风险、性能问题和可读性问题，并给出修改建议。
```

3. 逐条评估建议，采纳合理的部分；
4. 修改后再次交由智能体复审，形成闭环。

## 十二、常见问题（FAQ）

**Q1：登录时浏览器授权后 IDE 没反应？**
A：确认浏览器已完成登录并点击「授权」；若仍无反应，重启 IDE 后重试，并检查网络是否可访问华为云。

**Q2：智能体回答不贴合我的项目？**
A：在指令中显式引用相关文件，或让智能体先检索工程上下文；描述的越具体，结果越准。

**Q3：生成的代码不能运行？**
A：检查依赖版本、运行环境与测试框架是否一致，并把报错贴回对话让智能体修正。

**Q4：担心代码隐私与安全？**
A：遵守公司数据合规要求，涉及敏感信息时遵循华为云官方的数据安全说明；不要将密钥等机密写入提示词。

**Q5：提示无权限 / 未开通？**
A：回到华为云控制台确认 CodeArts 服务是否已开通、实名认证是否通过、账号是否具备相应权限。
